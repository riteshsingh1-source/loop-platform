# LOOP Business Demo

Interactive LOOP storefront and player demo. Start the connected server from the repository root with `npm run dev:connected`; use **Studio Admin** to start or stop the prerecorded FFmpeg broadcast to Amazon IVS. In replay mode, the player uses the CloudFront delivery for the S3 source video.

Visit http://127.0.0.1:4173 after starting the connected server from the repository root. Browser Picture-in-Picture requires localhost.
